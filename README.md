# BURN

<img src="assets/icon.png" alt="Логотип BURN" width="80">

Неофициальный десктоп-клиент YouTube Music на Tauri 2, Rust и React/TypeScript.
Не связан с Google, YouTube или Spotify. Доступность каталога и аудио зависит от сервисов и вашего аккаунта.

## Возможности

- Поиск, главная, библиотека, страницы альбомов, исполнителей и плейлистов.
- Очередь, перемотка, перемешивание, повтор и полноэкранный плеер с размытым фоном из обложки. В режиме караоке строки подсвечиваются в такт и по нажатию перематывают трек, если у текста есть таймкоды.
- На Windows значок BURN открывает мини-плеер над панелью задач, даже если основное окно свёрнуто. Чтобы значок был виден рядом с часами, перетащите его из меню `^` на панель или включите BURN в разделе **Параметры → Персонализация → Панель задач → Другие значки в области уведомлений**. Поиск в мини-плеере работает с YouTube Music и локальной библиотекой.
- Автопродолжение онлайн-музыки: после конца ручной очереди используются рекомендации YouTube Music. Пауза и смена трека отменяют запоздавшее продолжение; повтор имеет приоритет.
- Три отдельных списка: **Избранные** (сердечки приложения), **Любимые треки Spotify** (импорт) и **Любимые треки YouTube** (лайки самого YouTube Music).
- Сердечки приложения не меняют лайки YouTube. Онлайн-избранное синхронизируется через отдельный приватный плейлист с меткой приложения; локальные файлы не загружаются.
- Импорт публичных и доступных вашему аккаунту закрытых плейлистов Spotify, включая его избранное. Несопоставленные треки показываются отдельно; импорт не гарантирует наличие каждой записи в другом каталоге.
- Импорт списков треков из выгрузки Яндекс Музыки, без передачи учётных данных. Перед созданием закрытых плейлистов в YouTube Music можно выбрать нужные списки.
- Режим клипа в полном плеере показывает доступное видео или клип, связанный с записью, во встроенном проигрывателе YouTube. Если YouTube запрещает встраивание, ролик можно открыть в самом YouTube.
- Локальные аудиофайлы и обложки; локальный поиск и выдача по страницам, без загрузки всей библиотеки в интерфейс. Архив ссылок на плейлисты открывается без восстановления и не скачивает музыку.
- Подписанные обновления: проверка при запуске и в настройках, установка только после подтверждения.
- Discord Rich Presence: название, исполнители, обложка и позиция текущего трека в статусе. По умолчанию показ выключен.

## Установка

Готовые сборки публикуются в [Releases](https://github.com/vltstudio/burn/releases):

- Windows x64: установщик NSIS `.exe`.
- macOS Apple Silicon и Intel: отдельные `.dmg`.
- Linux x64: `.AppImage` и `.deb`.

Подписи Tauri защищают автообновления, но не заменяют Windows Authenticode или Apple Developer ID/notarization. Системные предупреждения о неизвестном издателе возможны.

## Разработка

Нужны Node.js 24, Rust 1.90+ и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для вашей ОС. На Windows необходимы MSVC Build Tools и WebView2; на macOS — Xcode Command Line Tools.

```sh
npm ci
npm run tauri dev
```

### Тестовая сборка Android

Установите через Android Studio SDK Platform 37.0, Platform-Tools, Build-Tools, Command-line Tools и NDK. Задайте `JAVA_HOME` (подойдёт JDK 21 из Android Studio), `ANDROID_HOME` и `NDK_HOME`. На Windows обычная команда Tauri требует включённого режима разработчика, чтобы создать символические ссылки на нативные библиотеки.

```sh
npm ci
rustup target add aarch64-linux-android
npm run tauri -- android build --debug --apk --target aarch64
```

APK находится в `src-tauri/gen/android/app/build/outputs/apk/`. Для эмулятора x86-64 установите таргет `x86_64-linux-android` и передайте `--target x86_64`. В этой тестовой версии автообновления для десктопа отключены на Android.

Проверки без запросов к личным аккаунтам:

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --workspace --locked
node .github/scripts/release.mjs check
node .github/scripts/release.mjs test
```

Сетевые Rust-тесты помечены `ignored` и не запускаются CI. Запускайте их отдельно и осознанно: они обращаются к реальным сервисам.

Для локальной сборки без ключа подписи создайте временный конфигурационный файл вне репозитория:

```json
{ "bundle": { "createUpdaterArtifacts": false } }
```

Передайте его абсолютный путь через `npm run tauri build -- --config <path> --bundles nsis` на Windows, `--bundles app,dmg` на macOS или `--bundles appimage,deb` на Linux.

## Вход и данные

Вход в Google и Spotify проходит в отдельных встроенных окнах сервисов. Google-сессия подтверждается запросом к YouTube Music до сообщения об успешном входе. Приложение сохраняет сессионные cookies локально; пароли вводятся только на страницах соответствующих сервисов.

Вход, настройки, архив, локальная библиотека и избранное сохраняются в каталоге конфигурации Tauri. На Windows это `%APPDATA%\com.ytmusicdt.app`. После переименования VLT Music в BURN идентификатор приложения, имя исполняемого файла, ключи хранилища и метка `[YtMusicDT:favorites:v1]` сохранены для совместимости. Установщик Windows обновляет прежнюю установку на месте.

Не публикуйте `auth.json`, `spotify.json`, личную библиотеку, `.env` или приватные ключи. Они исключены из Git. Локальные сессионные файлы содержат чувствительные данные; не передавайте их другим людям.

### Импорт из Яндекс Музыки

В библиотеке выберите **Импорт из Яндекс Музыки**. Закажите архив на [странице данных Яндекс ID](https://id.yandex.ru/personal/data), распакуйте его локально и выберите файлы JSON со списками треков Музыки. Импорт сначала показывает распознанные списки. Вход в Яндекс проходит только на его сайте; BURN не принимает пароли или токены. Для создания плейлистов нужен подтверждённый вход в YouTube Music. Подробнее — в [справке об архиве данных](https://yandex.ru/support/id/ru/data).

### Скачивание

Кнопка в плеере показывает официальные варианты: открыть трек в YouTube Music для офлайн-сохранения, когда оно доступно вашему аккаунту, или открыть YouTube Studio, чтобы скачать собственное загруженное видео. BURN не сохраняет обычные потоки каталога как отдельные файлы.

### Статус трека в Discord

Откройте **BURN → Настройки → Discord** и включите **Показывать музыку в Discord**. Идентификатор приложения BURN уже встроен. Запустите настольный Discord и включите трек. Discord показывает статус в соответствии с вашими [настройками видимости активности](https://support.discord.com/hc/en-us/articles/7931156448919-Activity-Sharing-on-Discord-FAQ).

Пауза и выключение показа убирают статус. BURN передаёт публичную обложку YouTube Music, если она доступна. Локальные треки скрыты по умолчанию; если разрешить их показ, BURN не передаёт пути к файлам и локальные обложки. Веб-версия Discord не поддерживается.

## Сборки и релизы

`Desktop CI` проверяет pull request и push в `main` на Windows x64, macOS ARM64/Intel и Linux x64 без ключей подписи.

`Signed desktop release` запускается тегом `v<version>` или вручную с соответствующим тегом. Версии в Tauri, npm, Cargo и обоих lockfile должны совпадать. Все платформы сначала загружают артефакты в общий черновик. Только после успешной сборки всех платформ публикуются полный `latest.json` и релиз; частичная сборка не становится обновлением.

Для релизов в GitHub Actions нужен секрет `TAURI_SIGNING_PRIVATE_KEY`; `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` необязателен для ключа без пароля. Публичный ключ находится в `src-tauri/tauri.conf.json`. Приватный ключ хранится отдельно от репозитория и должен иметь защищённую резервную копию: его потеря разорвёт обновления уже установленных версий.

Манифест обновлений: `https://github.com/vltstudio/burn/releases/latest/download/latest.json`.
Для автообновления используются NSIS `.exe`, macOS `.app.tar.gz` и Linux `.AppImage`; `.dmg` и `.deb` предназначены для установки вручную. Первая установка версии с поддержкой updater выполняется вручную.

## Структура

- `src/player.tsx` — аудио, очередь, автопродолжение и защита от запоздавших ответов.
- `src/updater.tsx` — проверка, загрузка и состояние обновлений.
- `src/components`, `src/views` — интерфейс и страницы.
- `src-tauri/src/ytm` — запросы YouTube Music и разбор ответов.
- `src-tauri/src/spotify.rs`, `import.rs` — чтение Spotify и сопоставление записей.
- `src-tauri/src/local.rs`, `favorites_sync.rs` — локальные данные и облачная копия избранного.
- `src-tauri/audio-resolver` — получение временных прямых аудиопотоков без Python или yt-dlp.
- `.github/workflows`, `.github/scripts/release.mjs` — сборки, подписи и публикация полного обновления.

PNG-источник иконки: `src-tauri/app-icon-source.png`; вариант со скруглением — `src-tauri/app-icon.png`. Готовые размеры находятся в `src-tauri/icons`.
